# A 的理论推导与核对说明

这份材料用于理解和检查英文报告 §2–§3。例子 2 已作为 A 的本地候选完成验证，尚未进入组内共享环境。已有理论、A 的参考验证器和未来 C 的正式实现必须分开表述。

## 一、统一符号

| 符号 | 含义 | 不应混淆的地方 |
|---|---|---|
| S_t、A_t、C_t | 本步状态、动作、实际代价 | C_t 是实现值，不是均值 |
| P(s′,c\|s,a) | 下一状态和本步代价的联合概率 | 不假设二者独立 |
| T、Z | 首次到终点的步数、之前总代价 | 进入终点的最后一步也付费 |
| J* | 期望总代价最优值 | 不是 CVaR 最优值 |
| α | CVaR 置信水平 | 最坏比例为 1−α |
| y、z、b | 起始阈值、已花代价、剩余预算 y−z | y 不是置信水平，不是硬截止时间 |
| B | 搜索的最大起始预算 | 不同于状态 B |
| W(s,b) | 最小期望超支 | 不是剩余总代价本身 |

## 二、γ=1 为什么仍然能求解

我们想优化真实累计分钟数，未来一分钟和现在一分钟都按一分钟计算。γ=1 使普通折扣压缩证明不能直接使用，但并不使所有动态规划失效。

有限 SSP 的标准条件包含：从所有状态存在 proper 策略；任何 improper 平稳策略至少从一个状态具有无穷期望代价。这里非终点每步至少付 1，所以 E[Z]≥E[T]；到达时间期望为无穷时，期望总代价也为无穷。对平稳策略，有限状态链的 transient 结构保证 proper 时 (I−Pμ) 可逆。

应引用 Bertsekas–Tsitsiklis 的标准 SSP 结论，不能把普通 γ<1 压缩证明中的 γ 直接替换为 1。相邻迭代差小也不是这里一般性的误差证书。两个验证例子本身均无环，所有策略至多两步／三步终止，比一般 SSP 条件更强。

## 三、期望塌缩究竟证明什么

以完整历史 H_t 为条件，模型假定未来联合结果只依赖当前状态和动作：E[C_t\|H_t,A_t]=c̄(S_t,A_t)。再利用非负性和全期望公式：

E[Z] = Σ_t E[1_{t<T}C_t] = Σ_t E[1_{t<T}c̄(S_t,A_t)]。

因此风险中性 Bellman 方程只需要单步均值与下一状态边际概率。最优平稳策略存在，所以最优期望值可以用均值代价问题计算。

边界：这不是说转移随机性消失。对一个观察历史代价的策略，若把观测也删掉，它可能不再以同样方式执行，不能无条件说“任意历史策略在删掉随机代价后行为完全不变”。若过去代价揭示未观测的持续拥堵，必须扩大状态，否则这里的 Markov 条件不成立。

## 四、CVaR 从定义走到预算 DP

对任一策略 π，令 Fπ(y)=y+Eπ[(Z−y)+]/(1−α)。静态 CVaR 是 inf_y Fπ(y)。由于策略与阈值都是在最小化：

inf_π inf_y Fπ(y) = inf_y inf_π Fπ(y)。

不是极小极大交换，所以这里不需要使用未证明的鞍点假设。

固定 y 后，已经花 z 时只需记 b=y−z。未来物理随机过程依赖 s，最终超支依赖剩余预算 b，因此 (s,b) 是充分的增广状态。

1. 已到 G：剩余代价为 0，超支是 (−b)+。
2. 非终点且 b≤0：未来代价非负，(Z_s−b)+=Z_s−b，故 W(s,b)=J*(s)−b，动作使用期望最优 proper fallback。
3. b≥1：先选动作、观察联合结果，再进入 (s′,b−c)，故 W(s,b)=min_a Σ P(s′,c\|s,a)W(s′,b−c)。

因为 c≥1，新预算严格下降。即使原地图有循环，正预算层也不会循环；有限正预算耗尽后进入 proper fallback。整数代价下，固定策略的目标对 y 在相邻整数间是线性的，因此可以选择整数最优阈值。

例子 1，y=7：到 M 时 b=6 或 −13。b=6 时 X 的期望超支为 2.4、Y 为 0；b=−13 时 X 为 16.9、Y 为 19。起点 W(S,7)=0.9×0+0.1×16.9=1.69，因此目标为 7+10×1.69=23.9。

例子 2，y=8：到 M 时 b=6、−12、−13。前者选 Y，后两者选 X，得到 YXX；W(S,8)=0.05×15.9+0.05×16.9=1.64，目标为 8+10×1.64=24.4。

## 五、预算上限怎样有依据

仅仅“最优 y 没碰到 B”不是全局保证，优化后的外层函数不必保持单一凸盆地。

若已有一个 proper 策略的 CVaR 上界 U，由于 W≥0，任何 y>U 的目标都大于 U，不能更好。负 y 也无需考虑：Z≥0 时 Fπ(y)=Eπ[Z]/(1−α)−αy/(1−α)，在负半轴上随 y 增加而下降。

所以 B=ceil(U) 是保守的充分界。例如取一个 proper 策略 μ，U=E[Zμ]/(1−α) 就是可用但可能很松的界。两个无环例子的全部策略总耗时分别不超过 50 和 51，因此可直接取有限支撑上限，无需猜测 B。

## 六、为什么穷举这些策略已经足够

两个例子唯一的选择点是 M，之前的可观察历史分别只有两种和三种。对应的 4／8 种确定性选择覆盖所有确定性历史策略；这个事实来自具体图结构，不能直接推广成所有无环图中“完整历史都等于状态＋已花代价”。

更一般地，固定 y 的期望超支问题可以使用确定性的增广状态策略。对于这两个有限决策树，随机策略还可以表示为确定性策略分布的混合。CVaR 作为分布的函数是下确界形式的凹函数，因此混合分布的 CVaR 至少是成分 CVaR 的加权平均，不会低于最小成分值。它与“同一概率空间中随机变量的线性组合下 CVaR 的凸性”不是同一操作，不能混淆。

## 七、整数分布计算与截断

按 z 从小到大传播 (s,z) 概率，正整数代价使每次都落在更大的整数格点。相同 (s,z) 可以合并；每条路径到终点的概率累加到对应总耗时。这避免的是格点投影误差，仍有浮点舍入；截断存在时还缺少尾部信息。

只报告截断概率小，不能保证均值／CVaR 准确。例如极小概率乘以极大代价，仍可贡献很大的尾部期望。D 的当前风险函数拒绝对非零 overflow 给出精确指标是合理的。A 的两个例子用完整支撑计算，不涉及这项近似。

## 八、四个理论辨析

- 非可加：两个独立耗时，各为 90% 的 1 和 10% 的 30。各自 CVaR₀.₉=30，但总和分布为 2(81%)、31(18%)、60(1%)，CVaR₀.₉=33.9，不是 60。
- 静态与嵌套：例子 1 在 M 重新优化条件 CVaR，会比较 X=30 与 Y=6 而选 Y；这与从起点承诺的静态最优 YX 不同。预算 DP 是保持起点目标的执行，并非证明静态 CVaR 原本就时间一致。
- 方差：偶尔特别快的 C，均值 10、方差 9；固定 B，均值 11、方差 0。若目标为均值+λ方差，C 为 10+9λ，B 为 11，只有 λ>1/9 才严格偏好 B。均值–方差的动态处理有额外困难，但不能声称 CVaR 天然没有时间一致性问题，也不能笼统说只把两个矩放进状态就解决。
- 折扣：单位单步代价时，总折扣代价为 (1−γ^T)/(1−γ)。固定平均 T 的均值保持扩散可降低这个期望；不能推广为所有代价结构下“γ<1 总是更冒险”。E9 的实际幅度仍由 C 的实验决定。

## 九、A 本地验证的状态

原有精确枚举、D 的有限支撑分布核对、E1 六个动作全部保留。新增的 A 参考预算 DP 只用于小型无环验证，不承担网格生产求解器的职责。

`check_budget_dp.py` 对两个例子各比较 α=0.5、0.8、0.9、0.95、0.99：参考 DP 最优值 = 独立穷举最优值 = 实际执行该策略的精确 CVaR，共 10 项精确一致。

α=0.9 时实际执行参考 DP 返回的预算策略，每个例子 seed=0…9，每个 seed 100,000 条，共 2,000,000 条轨迹。每条都通过环境 sample 接口抽样。

为核对“经验 CVaR”的标准误，利用已知精确 PMF 做 20,000 次多项分布重复抽样，每次样本量也是 100,000，重复计算同一个经验 CVaR 估计量。这是已知小模型下的参数模拟标准误，不是未知环境的通用估计方案，也不再使用上轮固定阈值估计量的 SE。

重复抽样显示经验 CVaR 有约 −0.05 分钟的有限样本偏差，已写入 CSV；20 个实际模拟结果均落在精确值的 3 个估计标准误以内。该随机诊断不等于严格置信覆盖保证，最优性仍由精确穷举证明。
