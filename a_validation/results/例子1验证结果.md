## 最坏 10% 的组成

- XX：(50×1% + 31×9%) / 10% = 32.9。
- XY：(31×9% + 26×1%) / 10% = 30.5。
- YX：(50×1% + 21×9%) / 10% = 23.9。
- YY：(26×10%) / 10% = 26.0。

最优策略为 YX；相对只看位置的最优策略 YY，CVaR 降低 2.1 分钟。
最优整数起始阈值为 7–21，因此不能要求求解器必须返回 7。
